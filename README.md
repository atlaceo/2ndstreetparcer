# 2ndstreetparcer

Telegram-бот на Python для поиска товаров в японском магазине **2nd STREET**.
Помогает выбирать товары по бренду, категории и бюджету, смотреть фотографии
и сохранять подборки в таблицу.

Учебный проект для портфолио: от получения HTML до интерактивного интерфейса
в Telegram и сохранения истории в SQLite.

## Возможности

- Поиск по ключевым словам: `/search nike`, `/search stone island`.
- Выбор мужских и женских категорий, сумок и аксессуаров.
- Максимальная цена в иенах: кнопки или `/search nike --max 10000`.
- До пяти карточек с большим фото, ценой, типом, размером и состоянием.
- Ссылки на товар и фотографию в полном размере.
- Кнопка **«Ещё 5»** с сохранением запроса и фильтров.
- Исключение ранее показанных товаров отдельно для каждого пользователя.
- История и позиция поиска сохраняются в SQLite после перезапуска.
- CSV текущей подборки: UTF-8 с BOM, разделитель `;`, открывается в Excel.
- Текстовая карточка, если Telegram не может загрузить изображение.

## Пример использования

```text
/search nike
  → Мужское
  → Кроссовки: низкие
  → До ¥10,000
  → Карточки товаров с фото и кнопками
  → Ещё 5 / Скачать CSV для Excel
```

В CSV входят название, цена в JPY, тип товара, размер, состояние, ссылка и фото.
Экспорт сохраняет именно товары из подборки над нажатой кнопкой.

## Стек

Python · python-telegram-bot · HTTPX · Beautiful Soup · SQLite · unittest

Сайт загружается асинхронно без автоматизации браузера. Категория и максимальная
цена передаются в фильтры сайта. Уже показанные товары исключаются по ID.

## Запуск на Windows

Понадобятся Python 3.13 или 3.14 и токен Telegram-бота от [@BotFather](https://t.me/BotFather).

Открой PowerShell в папке проекта:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

Открой `.env`, замени `PASTE_NEW_TOKEN_HERE` на свой токен и сохрани файл.
Не публикуй этот файл и не отправляй токен в переписке.
Если `.env` уже настроен, не копируй шаблон поверх него.

```powershell
.\.venv\Scripts\python.exe bot.py
```

Напиши боту `/start`. Остановка — `Ctrl+C`. После изменения кода нужен перезапуск.

## Запуск на Linux / macOS

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
# Укажи свой токен в .env.
.venv/bin/python bot.py
```

## Команды

| Команда | Действие |
| --- | --- |
| `/start`, `/help` | Инструкция |
| `/search nike` | Поиск с выбором категории и цены |
| `/search nike --max 10000` | Поиск с собственным пределом цены в JPY |
| `/reset_history` | Очистить свою историю и позиции поиска |

```text

csv_export.py           — экспорт подборки в CSV
test_bot.py             — карточки и обработчики команд

```

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

Автоматические тесты не используют токен и не обращаются к Telegram или магазину.
Проверяют обработчики, CSV, фильтры, историю, резервные фото и пагинацию.
GitHub Actions запускает их на Python 3.13 и 3.14 при push и pull request.

## Ограничения

- Для ответа бот должен быть запущен. Развёртывание 24/7 пока не настроено.
- По одному запросу просматриваются максимум пять страниц. «Ещё 5» продолжает поиск.
- Кнопки старых подборок действуют до перезапуска; хранятся последние десять меню каждого типа на пользователя.
- Названия товаров остаются на языке сайта. Тип переводится по словарю и может остаться на японском.
- Сохранение позиции помогает листать каталог, но не является мониторингом новых поступлений.
- История до установки функции исключения повторов неизвестна боту.
- Изменение разметки сайта может потребовать обновления парсера.

Проект демонстрирует сбор публичных данных. Он не связан с 2nd STREET и не
обходит авторизацию или ограничения доступа. Фотографии и описания принадлежат
соответствующим правообладателям.
