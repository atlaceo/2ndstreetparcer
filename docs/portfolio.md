# Описание проекта для портфолио

**2ndstreetparcer — Telegram-бот для поиска товаров на Python**

Разработан учебный бот для японского магазина 2nd STREET. Пользователь вводит
бренд или ключевые слова, выбирает категорию и предел цены. Бот присылает
карточки с фотографиями, ценами, размерами, состоянием и ссылками.

Кнопка «Ещё 5» продолжает подборку без повторов. История показанных товаров
сохраняется отдельно для каждого пользователя в SQLite. Результаты можно
выгрузить в CSV для Excel.

**Технологии:** Python, python-telegram-bot, HTTPX, Beautiful Soup, SQLite.
**Проверки:** unittest и GitHub Actions; сетевые ответы в тестах заменены заглушками.

Проект создан для обучения и демонстрации навыков с помощью Codex.
Это не коммерческий заказ и не сервис с настроенной работой 24/7.

## Как записать демонстрацию

1. Отправить `/search nike --max 10000`.
2. Выбрать «Мужское → Кроссовки: низкие».
3. Показать карточку, большое фото и переход на сайт.
4. Нажать «Ещё 5» и показать другие товары.
5. Скачать CSV и открыть его в Excel.

В кадре показывать только Telegram и таблицу; файл `.env` и токен не нужны.

## Короткое описание услуги

Разработка парсера одного сайта на Python с выгрузкой в CSV или Telegram.
Перед оценкой сроков и стоимости проверяется доступность данных на выбранном
сайте и согласуется список полей, объём сбора и критерии приёмки.
